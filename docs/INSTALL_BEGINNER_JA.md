# ArchivistPro — 初心者向けインストールガイド

> **バージョン:** 3.7.0 · **更新日:** 2026-08-20 · **プラットフォーム:** Windows 10/11 (64-bit)
>
> このガイドは、ソフトウェアのインストールに慣れていない方向けに手順を追って
> 書かれています。短く技術的な要約は **[システム管理者向けガイド](INSTALL_PRO_JA.md)** へ。

## 1. ArchivistPro とは?

建築・デザインのアーカイブ向けの、**完全オフライン**で動作するデスクトップ
アーカイブ管理ソフトです。プロジェクトフォルダーをスキャンし、ファイル名や
内容による検索、プレビュー、重複検出、そして (任意で) AI 支援検索を提供します。
**ファイルは元の場所に残ります** — アプリがファイルを移動・コピー・アップロード
することはありません。

## 2. 始める前に — 動作要件

| 要件 | 状態 |
|---|---|
| Windows 10 または 11 (64-bit) | 必須 |
| WebView2 Runtime | 最新の Windows には通常インストール済み。なければインストーラーが自動取得 |
| インターネット | ダウンロード時のみ。アプリ自体はオフラインで動作 |
| 管理者権限 | **不要** — ユーザーアカウントにインストールされます |

## 3. ダウンロード

1. ブラウザで次のアドレスを開きます:
   **https://github.com/ahmet3ddd/ArchivistPro/releases/latest**
2. **Assets** の下から次をダウンロードします:
   - **`ArchivistPro_3.7.0_x64-setup.exe`** ← 推奨
   - `ArchivistPro_3.7.0_x64_en-US.msi` ← 代替 (マシンレベルに**別の**コピーを
     インストールします。理由がわかっている場合のみ使用)
3. ファイルは通常 **ダウンロード** フォルダーに保存されます。

## 4. インストール

1. **`ArchivistPro_3.7.0_x64-setup.exe`** をダブルクリックします。
2. Windows **SmartScreen** が青い警告 (「Windows によって PC が保護されました」)
   を表示することがあります。パッケージがコード署名されていないためで、想定内です:
   **「詳細情報」** をクリックし、**「実行」** を押します。
3. セットアップウィザードに従います (既定の設定で問題ありません)。
4. インストールは数秒で終わり、アプリを起動できます。

> ℹ️ アプリを開くと左上のタイトル横にバージョン番号 (**v3.7.0**) が表示されます —
> 正しいバージョンを入れたかどうかをここで確認できます。

## 5. 初回起動

1. 初回起動時に **「初期セットアップ」** 画面が表示されます: *「最初の管理者
   (admin) アカウントを作成してください。」* ユーザー名とパスワード (6 文字以上)
   を決め、**「アカウントを作成」** を押します。
   > ⚠️ このパスワードは必ず控えてください — パスワードはこのコンピューター
   > だけに保存され、「パスワードを忘れた場合」のメールは**ありません**。
2. 作成したアカウントで**ログイン**します。
3. 短いウェルカムツアーが表示されます。**開始** で 30 秒ほどのツアーを見るか、
   **「ツアーをスキップ」** します — 後から設定の「ガイドを表示」で再表示できます。

## 6. アーカイブの設定: フォルダーを追加してスキャン

1. 左のレールから **ソースフォルダー** を開きます。
2. **「フォルダーを追加」** でプロジェクトのあるフォルダー (例: `D:\Projects`)
   を選びます。
3. アプリが **「今すぐスキャンしますか?」** と尋ねます — **スキャン** を押します。
   - スキャンオプションの **「フォルダーからプロジェクトを自動割り当て」** が
     有効なら、ルート直下のフォルダー名がプロジェクト名になります (推奨)。
4. スキャン時間はアーカイブの規模によります (数万ファイル → 数分、10 万ファイル
   規模 → 30 分程度)。完了するとスキャンレポートが表示されます。
5. 2 回目以降のスキャンは**大幅に速く**なります: 変更のないファイルはスキップ
   されます。

何がスキャンされる? **すべてのファイル**がアーカイブに登録されます (隠しファイル
とシステムファイルを除く — これらはレポートの「スキップ」欄に載ります)。DWG・
MAX・IFC・RVT・SKP・PDF・Office・画像/動画など **95 以上の形式**は特別に認識され、
本文テキスト・プレビュー・技術メタデータが抽出されます。

## 7. 旧世代 (3.2.2) からの移行

ArchivistPro 3.2.2 以前は**旧世代**のアプリです。3.7.0 はそれを置き換えるの
ではなく**並行して**インストールされます。データは安全です — 次の手順で移行:

1. ⚠️ 移行が完了して確認するまで、旧バージョンとそのデータを**削除しない**で
   ください。
2. 新しいアプリで **設定 → 一般** を開くと **「以前のバージョンが見つかりました」**
   カードが表示されます。
3. **「以前のバージョンからデータをインポート」** をクリックします。ウィザードが
   見つかったアーカイブファイルを一覧します — 実際のアーカイブは通常 **「メイン」**
   ラベル付きで最大サイズのものです。
4. まず **「ドライラン (何も書き込まない)」** を実行します: 実行した場合に何が
   起きるかを正確に表示します。
5. **「インポート」** を押します。実行前に自動バックアップが取られ、中断しても
   再実行は安全です。
   - **移行されるもの:** ファイルレコード、AI 分析、タグ、お気に入り、
     コレクション、フォルダー。
   - **移行されないもの:** ユーザーパスワード (新アプリで再作成) とチャット履歴。
6. インポート後、フォルダーを**再スキャン**してください — 高品質プレビューと
   本文テキストはスキャンで生成されます。移行されたタグと AI 分析は保持されます。

> ℹ️ インポート後もカードは消えません (元データは削除されないため) —
> **「最終インポート: …」** の行が表示されます。インポートが実行されなかった
> という意味ではありません。

## 8. AI 機能 (任意)

アプリは AI なしで完全に機能します。次も使いたい場合に AI を設定してください:

- **セマンティック検索** (「木製ファサード詳細」のような自由な検索) と
  **ビジュアル検索**
- **チャット** (アーカイブへの質問) と **画像分析** (AI による画像タグ付け)

設定: **設定 → AI → AI セットアップウィザード**

1. **検索モデル:** フォルダーからインポートします (完全オフライン)。
2. **チャット & 画像分析 (任意):** 無料の [Ollama](https://ollama.com) が必要
   です。Ollama がなくても検索は動作します。チャットと画像分析のみ無効です。
3. その後 **設定 → AI → セットアップチェック** で GPU/Ollama/モデルの状態を
   確認できます。

> 💡 NVIDIA GPU は AI を高速化しますが必須ではありません。GPU がある場合は
> ドライバーを最新に保ってください。

## 9. よくある質問

**ファイルはコピー/移動されますか?**
いいえ。アプリはインデックスを作るだけで、ファイルは元の場所に残ります。
フォルダーをリストから外してもファイルは削除されません。

**インターネットは必要ですか?**
いいえ。ダウンロード時 (と任意の Ollama インストール時) のみ必要です。
日常の利用は完全オフラインで、データが外部に送られることはありません。

**アップデート方法は?**
新バージョンの `setup.exe` をダウンロードして実行するだけです — 3.3.x の
インストールをその場でアップグレードし、データは保持されます。

**アンインストールするとアーカイブは消えますか?**
いいえ。アーカイブのデータベースはディスクに残り、再インストールすれば
続きから使えます。

**パスワードを忘れました — どうすれば?**
別の管理者アカウントがあればリセットできます。管理者が自分だけでパスワードを
紛失した場合、復旧手段はありません — パスワードは安全な場所に保管してください。
