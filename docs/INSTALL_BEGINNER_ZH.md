# ArchivistPro — 新手安装指南

> **版本:** 3.7.0 · **更新日期:** 2026-08-20 · **平台:** Windows 10/11 (64 位)
>
> 本指南面向不常安装软件的用户，逐步讲解。
> 更简短的技术摘要请见 **[系统管理员指南](INSTALL_PRO_ZH.md)**。

## 1. ArchivistPro 是什么?

一款为建筑与设计档案打造的、**完全离线**运行的桌面档案管理程序。它扫描您的
项目文件夹，提供按文件名和内容搜索、预览、查重，以及（可选的）AI 辅助搜索。
**您的文件保留在原位** — 程序不会移动、复制或上传任何文件。

## 2. 开始之前 — 系统要求

| 要求 | 状态 |
|---|---|
| Windows 10 或 11（64 位） | 必需 |
| WebView2 Runtime | 较新的 Windows 通常已自带；缺失时安装程序会自动下载 |
| 互联网 | 仅下载时需要；程序本身离线运行 |
| 管理员权限 | **不需要** — 安装到您的用户账户 |

## 3. 下载

1. 在浏览器中打开:
   **https://github.com/ahmet3ddd/ArchivistPro/releases/latest**
2. 在 **Assets** 下载:
   - **`ArchivistPro_3.7.0_x64-setup.exe`** ← 推荐
   - `ArchivistPro_3.7.0_x64_en-US.msi` ← 备选（在机器级安装**独立**副本；
     仅在明确知道用途时使用）
3. 文件通常保存在 **下载** 文件夹。

## 4. 安装

1. 双击 **`ArchivistPro_3.7.0_x64-setup.exe`**。
2. Windows **SmartScreen** 可能显示蓝色警告（「Windows 已保护你的电脑」）。
   这是因为安装包未做代码签名，属预期现象: 点击 **「更多信息」**，再点击
   **「仍要运行」**。
3. 按安装向导操作（默认设置即可）。
4. 安装几秒内完成，即可启动程序。

> ℹ️ 程序打开后，左上角标题旁会显示版本号（**v3.7.0**）— 可借此确认安装的
> 版本正确。

## 5. 首次启动

1. 首次启动会出现 **「初始设置」** 界面: *「创建第一个管理员 (admin) 账户。」*
   设定用户名和密码（至少 6 个字符），点击 **「创建账户」**。
   > ⚠️ 请记下该密码 — 密码只保存在这台电脑上，**没有**「忘记密码」邮件功能。
2. 用刚创建的账户**登录**。
3. 之后会出现简短的欢迎导览。点 **开始** 花 30 秒浏览，或点 **「跳过导览」** —
   以后可在设置中的「显示指南」重新打开。

## 6. 建立档案库: 添加文件夹并扫描

1. 在左侧栏打开 **源文件夹**。
2. 点击 **「添加文件夹」**，选择存放项目的文件夹（例如 `D:\Projects`）。
3. 程序询问 **「现在扫描吗?」** — 点击 **扫描**。
   - 若扫描选项中启用了 **「按文件夹自动分配项目」**，根目录下第一层文件夹名
     将成为项目名（推荐）。
4. 扫描时长取决于档案规模（数万文件 → 几分钟；约 10 万文件 → 半小时左右）。
   完成后会显示扫描报告。
5. 之后的扫描**快得多**: 未变化的文件会被跳过。

扫描包含什么? **您的全部文件**都会进入档案库（隐藏文件和系统文件除外 —
它们列在报告的「已跳过」部分）。程序对 **95 种以上格式** — 包括 DWG、MAX、
IFC、RVT、SKP、PDF、Office 及图像/视频 — 做专门识别: 提取正文文本、预览和
技术元数据。

## 7. 从旧一代版本 (3.2.2) 迁移?

ArchivistPro 3.2.2 及更早属于**旧一代**；3.7.0 不会原位替换它，而是**并列
安装**。您的数据是安全的 — 按以下步骤迁移:

1. ⚠️ 在导入完成并确认之前，**不要卸载**旧版本或删除其数据。
2. 在新程序中打开 **设置 → 常规**，会看到 **「发现先前版本」** 卡片。
3. 点击 **「从先前版本导入数据」**。向导会列出找到的档案文件 — 真正的档案
   通常带 **「主」** 标签且体积最大。
4. 先运行 **「试运行（不写入任何内容）」**: 它会准确显示将发生什么。
5. 点击 **「导入」**。操作前会自动备份；即使中断，重新运行也是安全的。
   - **迁移内容:** 文件记录、AI 分析、标签、收藏、集合、文件夹。
   - **不迁移:** 用户密码（请在新程序中重建账户）和聊天记录。
6. 导入后请**重新扫描**文件夹 — 高质量预览和正文文本由扫描生成；已迁移的
   标签和 AI 分析会保留。

> ℹ️ 导入后卡片不会消失（因为源数据从不被删除）— 卡片会显示 **「上次导入: …」**
> 一行。这并不代表导入没有执行。

## 8. AI 功能（可选）

不启用 AI 程序即完整可用: 扫描、按名称/内容搜索、预览、查重都开放。若还需要
以下功能，再配置 AI:

- **语义搜索**（如「木质立面节点」这类自由查询）和 **视觉搜索**
- **聊天**（向档案提问）和 **图像分析**（AI 自动为图片打标签）

配置入口: **设置 → AI → AI 设置向导**

1. **搜索模型:** 从文件夹导入（完全离线）。
2. **聊天与图像分析（可选）:** 需要免费的 [Ollama](https://ollama.com)。
   没有 Ollama 搜索仍可用；只有聊天和图像分析保持关闭。
3. 之后可在 **设置 → AI → 安装检查** 查看 GPU/Ollama/模型状态。

> 💡 NVIDIA 显卡可加速 AI，但不是必需。若有显卡，请保持驱动为最新。

## 9. 常见问题

**我的文件会被复制或移动吗?**
不会。程序只建立索引；文件留在原位。把文件夹从列表移除也不会删除文件。

**需要联网吗?**
不需要。只有下载（以及可选的 Ollama 安装）时需要；日常使用完全离线，
不会向外发送任何数据。

**如何更新?**
下载并运行新版本的 `setup.exe` — 它会原位升级您的 3.3.x 安装，数据保留。

**卸载后档案会被删吗?**
不会。档案数据库保留在磁盘上；重装后可继续使用。

**忘记密码怎么办?**
其他管理员账户可以重置。若您是唯一管理员且密码丢失，则无法恢复 —
请妥善保管密码。
