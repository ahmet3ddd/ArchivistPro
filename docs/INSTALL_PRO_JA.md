# ArchivistPro — システム管理者向けインストールガイド

> **バージョン:** 3.6.1 · **更新日:** 2026-08-18 · **プラットフォーム:** Windows 10/11 (64-bit)
>
> 手順を追った説明は **[初心者向けガイド](INSTALL_BEGINNER_JA.md)** へ。

## 1. 概要

```powershell
# ユーザーレベル・サイレント (推奨):
ArchivistPro_3.6.1_x64-setup.exe /S

# マシンレベル (意図的な選択 — 下の表を参照):
msiexec /i ArchivistPro_3.6.1_x64_en-US.msi /qn
```

コア機能 (スキャン、全文検索、プレビュー、重複検出) は**単一 exe で完全
オフライン**動作します。AI コンポーネントは任意です (§7)。

## 2. パッケージ種別 — NSIS と MSI は別物

| | **NSIS `setup.exe` (推奨)** | MSI |
|---|---|---|
| インストールレベル | ユーザー (管理者権限不要) | マシン (`Program Files`) |
| 場所 | `%LOCALAPPDATA%\ArchivistPro` | `C:\Program Files\ArchivistPro` |
| 3.3.x のアップグレード | **その場で更新** | 別製品としてインストール |
| サイレントスイッチ | `/S` | `/qn` |

> ⚠️ 同じマシンに setup.exe と MSI の両方を入れると、**独立した 2 つのコピー**が
> 並存します。どちらか一方を選んで使い続けてください。

パッケージはコード署名されていません。初回実行時の SmartScreen 警告は想定内です
(「詳細情報 → 実行」)。組織展開ではリリースページの SHA-256 で検証してください。

## 3. 前提条件

| コンポーネント | 備考 |
|---|---|
| **WebView2 Runtime** | 唯一の実質的必須要件。最新の Win10/11 には通常あり。なければ setup.exe が取得。オフライン機には[スタンドアロンインストーラー](https://go.microsoft.com/fwlink/?linkid=2124701)を事前導入。 |
| **VC++ 再頒布可能パッケージ x64** | 大半のマシンにあり。「VCRUNTIME140.dll が見つかりません」エラー時に [vc_redist.x64.exe](https://aka.ms/vs/17/release/vc_redist.x64.exe) を導入。 |

## 4. 配置場所

| 対象 | 場所 |
|---|---|
| アプリ本体 (NSIS) | `%LOCALAPPDATA%\ArchivistPro` |
| **アーカイブデータベース** | `%APPDATA%\com.archivistpro.h3\` |
| AI モデル (ONNX) | `%LOCALAPPDATA%\com.archivistpro.h3\models` |

- アンインストールしてもデータは**消えません**: アーカイブは `%APPDATA%` に
  残り、再インストール後に続きから使えます。
- バックアップ: アプリ内 **設定 → バックアップ** (重要操作の前には自動
  バックアップも取得)。ファイルレベルでは、アプリ終了状態で
  `%APPDATA%\com.archivistpro.h3\` をコピーすれば十分です。

## 5. マルチユーザーとロール

- 初回起動時に**最初の管理者アカウント**を作成します (パスワード 6 文字以上、
  完全にローカル保存 — 復旧メールはなく、唯一の管理者パスワードを失うと復旧
  手段はありません)。
- 追加アカウントは **設定 → ユーザー** から。ロールは本物の権限チェックで強制
  されます (閲覧専用ロールを含む)。書き込み権限は UI で隠すだけでなくコマンド
  レベルで検査されます。
- 無操作が続くとセッションは**ロック**され、ロック画面からユーザー切り替えが
  可能です。

## 6. 旧世代 (3.2.2 以前) からの移行

3.3.x は**異なるアプリケーション ID** を使います: 3.2.2 のその場アップグレード
ではなく、並行インストールでデータフォルダーも別です。

1. 移行を確認するまで旧バージョンとそのデータを**削除しない**。
2. 新バージョンで: **設定 → 一般 → 「以前のバージョンが見つかりました」** カード
   → **「以前のバージョンからデータをインポート」**。
3. ウィザードが検出したアーカイブを一覧します (「メイン」ラベルの最大のものが
   通常本物)。**「ドライラン」** は何も書き込まず、正確な結果を表示します。
4. **インポート**: 事前に自動バックアップを取得。処理は**冪等**です — 中断や
   再実行があっても既存レコードには触れません (「既存」としてカウント)。
   - 移行対象: ファイルレコード、AI 分析、タグ、お気に入り、コレクション、
     フォルダールート (+ 任意でゴミ箱レコード・一時プレビュー)。
   - 対象外: ユーザーパスワード (ハッシュ方式が異なる) とチャット履歴。
5. インポート後は**ルートを再スキャン** (本文テキスト/指紋/プレビューはスキャン
   で生成。移行済みの AI 分析とタグは保持)。

## 7. AI コンポーネント (任意) とオフライン展開

AI なしでもスキャン/検索/プレビューは完全動作します。AI を使うマシンでは:

1. **検索モデル (ONNX、完全オフライン):** **設定 → AI → AI セットアップ
   ウィザード → 検索モデル** でフォルダーからインポート。想定される 3 つの
   モデルディレクトリ:
   `paraphrase-multilingual-MiniLM-L12-v2` (テキスト) ·
   `clip-vit-base-patch32` · `clip-ViT-B-32-multilingual-v1` (画像)。
   既存インストールからのコピー元: `%LOCALAPPDATA%\com.archivistpro.h3\models`。
2. **チャット + 画像分析:** [Ollama](https://ollama.com) をインストール。
   - ネット接続あり: `ollama pull qwen2.5vl:3b`
   - オフライン: 別マシンの `%USERPROFILE%\.ollama\models` を対象マシンに
     マージコピー。
3. **検証:** **設定 → AI → セットアップチェック** が GPU・Ollama・画像分析
   モデル・検索モデルの状態をマシンごとに計測します。その後、実際のテスト
   実行を行ってください。
4. GPU 注意: NVIDIA GPU は画像分析を大幅に高速化します (CPU でも動作、ただし
   低速)。**古い NVIDIA ドライバー**は Ollama の GPU パスを壊すことがあります —
   対処はドライバー更新です (ハードウェア交換ではなく)。

## 8. DWG 詳細メタデータ (任意、推奨)

**ODA File Converter** がインストールされていればアプリが自動検出し (設定不要)、
DWG のレイヤー/ブロック抽出が充実します。なくても内蔵の純 Rust DWG パーサーが
動作します (基本情報は抽出されます)。ODA サイトから入手 (無料、要登録)。

## 9. トラブルシューティング

| 症状 | 対処 |
|---|---|
| SmartScreen のブロック | 「詳細情報 → 実行」。組織環境では SHA-256 を検証 |
| `VCRUNTIME140.dll` が見つからない | vc_redist.x64.exe を導入 (§3) |
| 白い/空のウィンドウ | WebView2 Runtime 不足 — スタンドアロン版を導入 (§3) |
| Ollama の GPU エラー (`unsupported PTX toolchain` など) | NVIDIA ドライバーを更新 |
| ArchivistPro が 2 つ見える | MSI と setup.exe の両方が入っている — 片方を削除 (データは `%APPDATA%` にあり消えない) |

## 10. アップグレードとアンインストール

- **3.3.x → 3.3.y:** 新しい `setup.exe` がその場でアップグレード (先にアプリを
  終了)。
- **アンインストール:** 設定 → アプリから。アーカイブデータは `%APPDATA%` に
  保持されます。データも消す場合は `%APPDATA%\com.archivistpro.h3\` を手動で
  削除してください。
